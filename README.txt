SIOMAY JAWARA — HOMEPAGE STARTER

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka folder siomay_jawara_homepage.
3. Klik dua kali index.html, atau buka dengan browser.
4. Untuk mengedit, buka index.html menggunakan Visual Studio Code.

Catatan:
- Ini adalah prototype frontend landing page.
- Navigasi, scroll reveal, partikel, tombol WhatsApp, dan tautan sosial sudah aktif.
- Katalog menampilkan harga awal dari foto menu yang diberikan.
- Belum ada login, database, keranjang/checkout terintegrasi, sinkronisasi stok, atau dashboard aktor. Fitur-fitur tersebut dibuat pada tahap backend berikutnya.
- Gambar hero adalah visual konsep hasil generasi AI, bukan foto produk asli Siomay Jawara.
- Pastikan jam operasional, harga, alamat, dan kontak diverifikasi sebelum website dipublikasikan.
